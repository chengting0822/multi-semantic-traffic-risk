# 車輛偵測與追蹤

[回到首頁](../README.md) · [研究方法](methodology.md) · [模型架構](models.md)

影像前端將道路影片轉為具有車輛 ID 的逐幀軌跡，同時記錄號誌狀態，提供後續速度、車道與風險分析使用。

## 影像處理流程

1. **YOLO 車輛偵測**：取得偵測框、類別與置信度。
2. **ByteTrack 多目標追蹤**：將不同影格中的偵測結果連成同一車輛的軌跡。
3. **號誌 ROI 與輕量 CNN**：對預先標定的號誌區域辨識紅／綠燈狀態與機率。
4. **時間戳對齊**：依各影片的 FPS 將影格編號轉換為秒數，供後續固定時間窗分析。

後續風險研究目前聚焦於汽車。偵測品質、遮擋、類別跳動與 ID 切換會影響軌跡，因此它們也是研究限制與品質檢查的重點。

## 研究期間的主要設定

| 設定 | 值 | 用途 |
|---|---:|---|
| 車輛偵測模型 | YOLO26x | 偵測道路中的交通工具 |
| 推論影像尺寸 | 1280 | 保留較多遠處車輛資訊 |
| 偵測置信度門檻 | 0.18 | 保留候選偵測結果供追蹤使用 |
| NMS IoU 門檻 | 0.55 | 抑制重複偵測框 |
| 多目標追蹤 | ByteTrack | 維持車輛 ID 與軌跡 |
| 號誌 CNN 最低接受機率 | 0.55 | 篩選號誌分類結果 |
| GPU 推論精度 | FP16 | 研究環境下的 GPU 推論設定 |

上述設定反映研究期間的影像前端；攝影機視角、解析度與運算設備不同時，仍需要重新確認參數與道路標定。

## 軌跡提供哪些資訊？

每筆觀測包含影格編號、時間戳、車輛 ID、偵測框位置、置信度與類別，以及號誌狀態和分類機率。這些資訊再與道路幾何結合，轉換為超速、闖紅燈與異常軌跡語意。

目前公開版本提供研究說明與成果展示。程式碼、權重及操作方式仍在整理中，完成後將更新上線。
