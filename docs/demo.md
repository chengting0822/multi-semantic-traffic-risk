# 展示案例

[回到首頁](../README.md) · [研究方法](methodology.md) · [模型架構](models.md)

四個案例展示多種高風險交通行為，以及系統對單一車輛與整體場景風險的評估。展示影片為研究流程產生的結果；目前公開版本以成果說明與影片觀看為主。

## 觀看重點

1. **停等紅燈後逆向行駛並闖紅燈**：觀察車輛從正常停等轉為異常行為後，風險資訊如何隨時間改變。
2. **高車流情境下蛇行穿梭**：觀察蛇行車輛與周遭車流的互動，以及整體場景風險的變化。
3. **逆向行駛且嚴重超速**：觀察方向異常與高速行駛同時出現時的風險評估。
4. **逆向、超速與闖紅燈的複合違規**：觀察多種交通語意同時成立時，單一車輛與場景層的綜合判斷。
